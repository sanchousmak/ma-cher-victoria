# Ma chere Victoria

Статический сайт художницы с русской и английской версиями.

## Сборка

Для сборки нужен Node.js 18+ (зависимостей npm нет):

```bash
npm run build
```

Скрипт читает единственный контентный шаблон `src/index.template.html` и словари `src/locales/ru.json`, `src/locales/en.json`, проверяет совпадение ключей и отсутствие незаменённых маркеров, затем создаёт:

- `index.html` — маршрутизатор с сохранением `search/hash`;
- `ru/index.html` — русскую страницу;
- `en/index.html` — английскую страницу.

Сгенерированные HTML-файлы не редактируются вручную. Контент меняется в шаблоне и словарях, после чего повторно запускается `npm run build`.

На локальном сервере проверяйте сайт из корня репозитория, например:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`. Переключатель языка сохраняет английский выбор в `localStorage` под ключом `mcv-locale`; при отсутствии сохранённого выбора используется русский.
